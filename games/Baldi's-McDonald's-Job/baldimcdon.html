Baldi's McDonalds Job

3.0 Is released! I have put it on a new page thinking it may get more views. But you can download the original here: Baldi's McDonalds Job (Legacy) by JasenC4Plays (itch.io)

JOIN THE DISCORD SERVER HERE: https://discord.gg/cWXnZrF9eW

ANNOUNCEMENT 9/20/24: You can now play on the webpage!

ANNOUNCEMENT 9/19/24: MACOS 5.0.1 is out!

ANNOUNCEMENT 8/7/24: Version 5.0.1 hotfix is released! Fixed a bug to where getting jump scared would freeze your game.

ANNOUNCEMENT 8/7/24: Version 5.0 has been released! Here is an update log!

  1. There are two new styles! Virus Style, and Horror Style!
  2. You can now click on the version number to bring you to this page! Along with that, you can also now click the names in the bottom left to bring you to the Itch Io pages! There is also now a button to join the Discord!
  3. There is a new button on the main menu that allows you to look at the main menu from version 2.0 of Baldi's McDonalds Job!
  4. Each style now has its own artwork, just like Baldi's Basics Classic Remastered does!
  5. The options menu has now been fixed! It has had really small buttons up until this point.
  6. The mod credits have now been more organized and updated as well!
  7. The Custom Map Beta has now been updated to version 1.1! Along with beating that style, you unlock a new secret style! (Which is also accessible in the Custom Map Beta style selection if you feel lazy and do not want to beat the Custom Map Beta.)
  8. The Baldi TV now activates when getting all of the menus!
  9. There is a new item called "A McFlurry For Baldi"! It acts exactly like An Apple For Baldi. (Keep in mind, do NOT try to push Baldi with the Grimace Shake while he is drinking the McFlurry, it does not work.)
  10. Baldi's speed has FINALLY been optimized for the number of menus you have to collect!
  11. When getting a problem right on the MathMachine, Baldi will now stop to congratulate you! (Same rules apply from the McFlurry). 
  12. The bug has now been fixed where the second MathMachine in Scratch Style changed back to the original MathMachine model.
  13. To get to the secret ending, you now have to get the MathMachine in the first room wrong, and make sure you do it in Classic Style!

Keep in mind, there may still be a lot of bugs that I haven't found yet. If you find any more bugs, please report them in the Dsicord server, or on this page! A MacOS port will also be coming soon! Enjoy the new update!

ANNOUNCEMENT 7/26/24: Version 4.8 has been released! Sorry for the long wait time, I was on vacation for about 2 months, and I have also been working on other projects. Null mode has been removed from official 4.8 (for now...) due to me starting from the 4.2 decompile. Also, it is for now limited to Windows 64 bit. Enjoy the new update! Also a huge thanks to NatanBaldi for some of the textures in the new scratch style!

ANNOUNCEMENT 6/24/24: HUGE ANNOUNCEMENT! FIRST MAC PORT HAS BEEN RELEASED! It is called version 4.3 because it is 4.2 with minor bug fixes. So you will get a special version for your platform Mac users!

ANNOUNCEMENT 3/7/24: 4.8 will be really delayed due to pc space, so here is beta 4.8 for now! https://jasenc4plays.itch.io/bmj-testers
